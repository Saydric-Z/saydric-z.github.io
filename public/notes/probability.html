Univariate Discrete Probability Distribution

Random Variable: \(X\) is a function \((X: S \rightarrow \mathbb{R})\) that assigns a real number to each point in a sample space \(S\).
Discrete Random Variable: a set is countable if its element placed in one-to-one.
Probability Mass Function: \(f(x) = \mathbb{P}(X=x)\) for all \(x \in \mathbb{R}\). The set of pair \(\{(x, f(x)): x \in \mathbb{R}\}\) is the probability distribution
PMF properties:

  • \(f(x) \ge 0\) for all \(x \in \mathbb{R}\)

  • \(\sum_x f(x) = 1\)

Cumulative Distribution Function(CDF): \(F(x) = \mathbb{P}(X \le x)\)

CDF properties:

  • \(0 \le F(X) \le 1\) for all \(x \in \mathbb{R}\).

  • \(F(X)\) is non decreasing function for all \(X \in \mathbb{R}\).

  • \(\lim\limits_{x \to -\infty} F(X+h) = 0\).

  • \(\lim\limits_{h \to \infty}F(X+h) = 1\)

  • \(\lim\limits_{h \to 0^{+}}F(X+h) = F(X)\).

Remark: \(f(a_i) = F(a_i) - F(a_{i-1})\) for \(x \ge 2\)

Function of Random Variable: If \(X\) is a discrete random variable with range \(\mathbb{A}\), then \(Y = g(X)\) is also discrete random variabel, and its pmf can be determined using the pmf of X.

\[f_{Y}(y) = \mathbb{P}(Y=y) \quad \text{for any value of } y\] \[g(x) = y, \{x \in \mathbb{A}: g(x) = y\}, \quad \text{define}: f_{X}(x) = \mathbb{P}(X=x)\] \[f_{Y}(y) = \sum_{{x \in \mathbb{A}: g(x) = y}} f_{X}(x)\]

Y_{r}\) and define \[W = \sum_{j=1}^{r}d_{j}Y_{j}\] where \(d_{1}, d_{2}, ... , d_{r}\) are real constants and \(\alpha_{j} = \mathbb{E}(Y_{j})\) for \(j = 1, 2, ... , r\). \[\begin{align*} \mathrm{Cov}(V, W) &= \mathbb{E}((V - \mathbb{E}(V)) (W - \mathbb{E}(W))) \\ &= \mathbb{E}\left( \left(\sum_{i=1}^{n} c_{i}(X_{i} - \mu_{i})\right) \left(\sum_{j=1}^{r} d_{j}(Y_{j} - \alpha_{j})\right) \right) \\ &= \sum_{i=1}^{n} \sum_{j=1}^{r} c_{i}d_{j} \mathbb{E}((X_{i} - \mu_{i})(Y_{j} - \alpha_{j})) \\ &= \sum_{i=1}^{n} \sum_{j=1}^{r} c_{i}d_{j} \mathrm{Cov}(X_{i}Y_{j}) \end{align*}\]

Conditional Probability Distribution

Suppose that \(X\) and \(Y\) are discrete random variables with joint \(pmf f(x,y)\).Let \(f_X(x)\) be the marginal \(pmf\) of \(X\) and let \(f_Y(y)\) be the marginal \(pmf\) of \(Y\). The conditional probaility mass function(pmf) of \(X\) given \(Y = y\) is \[f_{X|Y}(x|y) = p(X=x|Y=y) = \frac{P(X=x|Y=y)}{P(Y=y)} = \frac{f(x,y)}{f_Y(y)}\] provided that \(f_Y(y) > 0\) Similarly, the conditional \(pmf\) of \(Y\) given \(X=x\)is \[f_{Y|X}(y|x) = P(Y=y|X=x)=\frac{X=x, Y=y} {P(X=x)} = \frac{f(x,y)}{f_X(x)}\] provided that \(f_X(x) > 0\)

for \(f_{Y|X}(y|x) \ge 0\) and \(f_{X|Y}(x|y) \ge 0\), moreover \[\sum_{all x}f_{X|Y}(x|y) = 1 and \sum_{all y}f_{Y|X}(y|x) = 1\] If \(X\) and \(Y\) are independent random variables, then \(f(x, y) = f_X(x)f_Y(y)\) for all \((x,y)\) implies that

Point Estimate and Maximum Likelihood Estimation

A point estimate of a parameter is the value of a function of the observed data \(y_1, \dotsc, y_n\) and other known quantities, use \(\bar{\theta}\) to denote an estimate of the parameter \(\theta\). Likelihood Function for Discrete Distribution: \[L(\theta) = L(\theta; y) = P(Y = y; \theta) \indent \text{for} \theta \in \varOmega\] where the parameter space \(\varOmega\) is the set of possible value for \(\theta\).

Maximize Likelihood Esitmation (MLE): If the value of \(\theta\) which maximize the probability of observing the data \(y\). Denote as \(\bar{\theta}\). Example: \(Y \sim Bin(n, \theta)\) \[L(\theta) = P(Y = y; \theta) = \binom{n}{y}\theta^y(1-\theta)^{n-y} \indent \text{for} 0 \le \theta \le 1\] Assume \(y \ne 0\), \(y \ne n\), let \(\frac{dL(\theta)}{d\theta} = 0\). \[\begin{align*} 0 &= \binom{n}{y}\left[y\theta^{y-1}(1-\theta)^{n-y} + \theta^y(1-\theta)^{n-y-1}(-1)(n-y)\right]\\ &= \binom{n}{y}\theta^{y - 1}(1-\theta)^{n-y-1}(y(1- \theta) - \theta(n-y))\\ &\Rightarrow y - y\theta - n\theta + y\theta = 0 \\ &\Rightarrow y = n\theta \text{\indent Sample Proportion} \end{align*}\]
Relative Likelihood Function: \[R(\theta) = \frac{L(\theta)}{L(\bar{\theta})} \indent \text{for} \theta \in \varOmega, 0 \le R(\theta) \le 1, \forall \theta \in \varOmega\]
Log Likelihood Function: \[l(\theta) = \ln L(\theta) = \log L(\theta) \indent \text{for } \theta \in \varOmega\] Since the \(\log\) function is a monotonw funciton of \(L(\theta)\), two function increase and decrease toether. Both fucntions have a maximum at the same value \(\theta = \hat{\theta}\)



Example: Likelihood Function for Poisson Distirbution \[\begin{align*} L(\theta) &= \prod_{i=1}^{n} \frac{\theta^{y_i} e^{-\theta}}{y_i!} \\ &= \left( \prod_{i=1}^{n} \frac{1}{y_i!} \right) \theta^{\sum y_i} e^{-n\theta} \\ &\propto \theta^{n\bar{y}} e^{-n\theta} \quad \text{for } \theta \ge 0 \\ \\ l(\theta) &= \log(L(\theta)) = n\bar{y}\log\theta - n\theta + \text{constant} \\ \frac{d l(\theta)}{d\theta} &= \frac{n\bar{y}}{\theta} - n \\ \text{Set derivative to 0: } & \frac{n\bar{y}}{\hat{\theta}} - n = 0 \\ &\implies \hat{\theta} = \bar{y} \quad \text{maximizes } l(\theta) \end{align*}\]

The \(pdf\) of Student’s \(t\) distribution: \[f(t;k) = c_k\left(1+\frac{{t}^2}{k}\right)^{-\frac{k+1}{2}} \indent \text{for } t\in \mathbb{R}\text{ and } k = 1, 2,\dotsc\] where \[c_k= \frac{\Gamma(\frac{k+1}{2})}{\sqrt{k\pi}\Gamma(\frac{k}{2})}\] The parameter \(k\) is the degrees of freedom. Denote as \(T\sim t(k)\) to indicate that the random variable \(T\) has \(t\) distribution with \(k\) degrees of freedom.For smaller k(such as \(k=2\)), the peak of \(t\) distribution is lower and has "fatter tails" at both ends.
